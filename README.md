# Punnami Tourism Website

A complete responsive tourism landing page built with **HTML + CSS only**.

## Project structure

```text
punnami-tourism/
├── index.html
├── style.css
└── assets/
```

## How to run

1. Keep `index.html`, `style.css`, and the `assets` folder together.
2. Open `index.html` in Chrome, Edge, Firefox, or another browser.
3. No JavaScript is required.

## Sections included

1. Transparent hero/header
2. Quick trip information
3. Package introduction
4. Destination cards
5. Day 1 & Day 2 itinerary timeline
6. Experience highlights
7. Travel gallery
8. Forest food section
9. FOOD MENU & GUIDELINES
10. Booking CTA
11. Footer

## Customization

Change the phone number and email in `index.html`:
- `+91 99999 99999`
- `info@punnamitourism.com`

Replace the placeholder booking/contact details with your real business details.
